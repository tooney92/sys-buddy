# sys-buddy v2.15.0 — 2026-08-17

Minor release. **A verified todo now wears a green check in the panel.** No schema change,
dashboard-only. Restart any long-running broker so it serves the new `ui.html` (or just
hard-reload the dashboard).

## Added

### A green check on a done todo

The todo panel carried a `1/4 verified` tally at the top but nothing on the rows themselves,
so "which one is done?" meant opening each todo to read its stepper. Now a **verified** todo
— or an owner-**confirmed** one on an engagement — wears a small green ✓ on the leading edge
of its row, so the answer is a glance instead of four clicks. On a debug task the same badge
marks a **resolved** issue.

It sits where the "awaiting acceptance" ⚠ sits and is mutually exclusive with it: a todo is
never both waiting on someone and finished, so the two markers never collide.

## Migration

None. Dashboard-only, no schema and no API change. **Restart any long-running broker** so it
serves the new page (an open dashboard just needs a reload).
